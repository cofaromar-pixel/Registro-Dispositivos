Importar / Exportar Dispositivos.csv

El archivo debe tener las columnas Tipo (Celular / Ringscanner / Tablet), Nombre (número identificador del dispositivo) y Marca (opcional). Si un dispositivo ya existe (mismo tipo y número) se actualiza; si es nuevo, se agrega. Si no viene la marca, se completa como "Pendiente" para que el guardia la vaya cargando después.

Importar legajos desde CSV

El archivo debe tener las columnas Nro Legajo (DNI del operario) y Nombre (formato "Legajos.csv"). Si un legajo ya existe se actualiza el nombre; si es nuevo, se agrega. Los legajos que no figuren en el archivo no se eliminan automáticamente.

Usá "Limpiar legajos" antes de importar un archivo Legajos.csv que reemplace por completo la base actual (por ejemplo, si cambiás el criterio de numeración a DNI).
